"Aplikasi ini dibangun dengan Vue 3 Composition API, Tailwind CSS, dan database PostgreSQL Supabase."

"Pertama, pada file src/App.vue di baris 3 sampai 26, kita memisahkan dua tampilan utama menggunakan state currentView: yaitu halaman publik pelanggan dan halaman Dashboard Admin yang dikunci oleh penjaga autentikasi adminStore.isAuthenticated."

"Untuk koneksi database, kita buka src/services/supabaseClient.js. Di baris 52 sampai 75, fungsi getSupabase() menghubungkan aplikasi ke server cloud Supabase. Lalu di bagian bawah pada baris 979 sampai 998, fungsi subscribeRealtime() membuka jalur WebSocket real-time agar perubahan stok atau pesanan langsung tampil otomatis tanpa refresh halaman."

SEGMEN 2: Fitur KF-01 — Katalog 74 Produk, Filter, & Validasi Stok 01:00 – 02:15 (1 Menit 15 Detik)
🖥️ Aksi Layar: Buka src/components/ProductGrid.vue (Baris 301–374) lalu src/components/ProductCard.vue (Baris 15–75)

"Masuk ke fungsi utama pertama yaitu KF-01: Katalog Produk Real-Time. Data 74 produk pakan diambil dari database melalui fungsi getProducts() di supabaseClient.js baris 117."

"Di file src/components/ProductGrid.vue pada baris 328 sampai 365, terdapat computed property filteredProducts. Kode ini bekerja secara reaktif menyaring produk berdasarkan 3 hal sekaligus: filter kategori ternak di baris 301, pencarian kata kunci di baris 331, dan pengurutan harga di baris 351. Lalu di baris 371, fungsi paginatedProducts membatasi 12 produk per halaman agar website tetap ringan."

"Selanjutnya di src/components/ProductCard.vue baris 15 sampai 22, sistem mengecek sisa stok (product.stock > 0). Jika stok habis, status otomatis berubah menjadi Stok Habis dan tombol tambah keranjang di baris 66 otomatis terkunci."

🖥️ Aksi Layar: Buka src/stores/useCartStore.js (Baris 30–136)

"Fungsi utama kedua adalah KF-02: Keranjang Belanja yang berada di src/stores/useCartStore.js."

"Di baris 30 sampai 73, terdapat fungsi syncCartWithLiveProducts() yang memastikan harga dan batas stok di dalam keranjang pelanggan selalu sinkron dengan database terbaru."

"Saat pembeli klik tambah produk, fungsi addToCart() di baris 111 sampai 136 dijalankan. Di baris 123, rumus Math.min(existing.qty + addQty, currentStock) mencegah pembeli memesan melebihi stok fisik di gudang. Total belanja dihitung otomatis oleh totalPrice di baris 90 dan disimpan ke localStorage di baris 76."

SEGMEN 5: Fitur KF-04 — Otentikasi Login Admin (Supabase Auth) 04:30 – 05:30 (1 Menit)
🖥️ Aksi Layar: Buka src/components/admin/AdminLoginView.vue (Baris 179–200)

"Sekarang kita masuk ke sisi pengelola melalui fungsi keempat yaitu KF-04: Portal Login Admin di src/components/admin/AdminLoginView.vue."

"Saat admin menekan tombol masuk, fungsi handleLogin() di baris 179 memanggil adminStore.loginAdmin() yang menjalankan fungsi autentikasi di supabaseClient.js baris 777 sampai 810."

"Pada baris 782, sistem memverifikasi email dan password menggunakan client.auth.signInWithPassword() dari Supabase Auth. Selain itu, fungsi checkAuthSession() di useAdminStore.js baris 78 memeriksa token JWT aktif, sehingga halaman dashboard aman dari akses tanpa izin."

"Di dalam Dashboard Admin, terdapat dua fungsi utama terakhir yaitu KF-05 (CRUD Katalog Produk) dan KF-06 (Validasi Pesanan WhatsApp & Potong Stok Otomatis) yang berpusat di src/stores/useAdminStore.js."

"Untuk KF-05 (Kelola Produk): fungsi addProduct() di baris 995 menangani tambah produk baru ke Supabase, fungsi updateProduct() di baris 1045 untuk mengubah harga atau isi ulang stok gudang, dan fungsi deleteProduct() di baris 1093 untuk menghapus produk."
